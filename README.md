# Кинотеатры «Салют» — главная страница

Адаптивная афиша для двух кинотеатров в Ставрополе: «Салют Центр» и «Салют Юг».

Основной интерфейс и данные находятся в `src/App.jsx`, оформление — в `src/index.css` на Tailwind CSS. Сгенерированные постеры в формате WebP лежат в `public/posters/`.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка для локального просмотра: `npm run build`, результат появится в `dist/`.

## GitHub Pages без отдельного workflow

Для публикации из ветки Pages должен отдавать именно собранный статический сайт, а не исходные файлы Vite. Сборка для project site `https://maketostep.github.io/salutcinema/` создаётся командой:

```bash
npm run build:pages
```

Она помещает результат в `docs/`; эту папку нужно включать в коммиты. В **Settings → Pages** выберите **Deploy from a branch**, нужную ветку и папку **`/docs`**. Чтобы обновить сайт после изменений, повторно выполните `npm run build:pages` и включите обновлённую `docs/` в push.

В афише выбраны реальные фильмы российского проката октября 2026 года. Расписание сеансов и счётчики лайков демонстрационные; постеры — оригинальные иллюстрации, сгенерированные для макета, а не официальные афиши. Покупка билетов показана в демо-режиме без подключения кассовой системы.
